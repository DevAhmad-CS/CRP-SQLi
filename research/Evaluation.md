## 1. التقييم على Validation Set

### الهدف:
- تقييم أداء كل نموذج على حدة
- مقارنة النماذج
- اختيار الأفضل قبل الاختبار النهائي

### المقاييس المستخدمة:

#### أ) Accuracy (الدقة)
- **المعنى:** نسبة التنبؤات الصحيحة من إجمالي التنبؤات
- **الصيغة:** (True Positives + True Negatives) / Total
- **لماذا مهم:** يعطي فكرة عامة عن أداء النموذج

#### ب) Precision (الدقة الإيجابية)
- **المعنى:** من بين جميع التنبؤات الإيجابية (SQL Injection)، كم منها صحيح
- **الصيغة:** True Positives / (True Positives + False Positives)
- **لماذا مهم:** يقلل من False Positives (استعلامات طبيعية مصنفة كـ SQL Injection)

#### ج) Recall (الاستدعاء)
- **المعنى:** من بين جميع حالات SQL Injection الحقيقية، كم منها تم اكتشافها
- **الصيغة:** True Positives / (True Positives + False Negatives)
- **لماذا مهم:** يقلل من False Negatives (SQL Injection غير مكتشفة)

#### د) F1-Score (مقياس متوازن)
- **المعنى:** متوسط توافقي بين Precision و Recall
- **الصيغة:** 2 × (Precision × Recall) / (Precision + Recall)
- **لماذا مهم:** يعطي توازن بين Precision و Recall (المقياس الأفضل)

## 3. Confusion Matrix

### ما هو Confusion Matrix؟

مصفوفة توضح:
- **True Positives (TP):** SQL Injection تم اكتشافها بشكل صحيح
- **True Negatives (TN):** استعلامات طبيعية تم تصنيفها بشكل صحيح
- **False Positives (FP):** استعلامات طبيعية مصنفة خطأ كـ SQL Injection
- **False Negatives (FN):** SQL Injection غير مكتشفة

### لماذا مهم؟

- **يوضح أنواع الأخطاء:** أين يخطئ النموذج
- **يساعد في التحسين:** معرفة ما يحتاج تحسين
- **توضيح بصري:** سهل الفهم

### النتائج من Confusion Matrix:

- **True Negatives:** عالي جداً (معظم الاستعلامات الطبيعية صحيحة)
- **False Positives:** قليل جداً (0.23%)
- **False Negatives:** قليل جداً (0.81%)

#### Logistic Regression على Test Set:
- **True Positives:** عالي جداً (معظم الهجمات مكتشفة)
