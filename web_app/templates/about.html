Overview

This SQL Injection Detection System is a machine learning-based solution designed to identify and prevent SQL injection attacks in real-time. The system uses advanced Natural Language Processing (NLP) techniques combined with Support Vector Machine (SVM) classification to achieve high accuracy in detecting malicious SQL queries.

Technology Stack

Machine Learning: Scikit-learn, SVM, Logistic Regression
NLP: TF-IDF Vectorization
Backend: FastAPI, Python
Frontend: HTML, CSS, JavaScript

Key Features

  • ✅ Real-time SQL query analysis
  • ✅ High accuracy (99.53% on test set)
  • ✅ Low false positive rate (0.23%)
  • ✅ Fast prediction response
  • ✅ Confidence score for each prediction
  • ✅ Support for various SQL injection patterns

Model Performance

The model was trained on a dataset of 25,278 SQL queries and achieved the following performance metrics on the test set:

  • Accuracy: 99.53%
  • Precision: 99.77%
  • Recall: 99.19%
  • F1-Score: 99.48%

Dataset

The training dataset consists of:

  • 17,694 training samples
  • 3,792 validation samples
  • 3,792 test samples
  • Balanced dataset (83.33% balance ratio)
  • 126 additional SQL injection patterns
