### 3. تحويل النص إلى أرقام: TF-IDF

**التقنية:** TF-IDF (Term Frequency-Inverse Document Frequency)

**الإعدادات:**
```python
TfidfVectorizer(
    max_features=10000,      # أفضل 10,000 ميزة
    ngram_range=(1, 3),      # كلمات مفردة، ثنائية، ثلاثية
    min_df=2,                # الحد الأدنى لتكرار الوثيقة
    max_df=1.0,              # الحد الأقصى لتكرار الوثيقة
    lowercase=False,         # الحفاظ على الحالة (مهم لـ SQL)
    sublinear_tf=True        # تطبيق قياس TF تحت خطي
)
```

**لماذا TF-IDF؟**
- يلتقط الكلمات المفتاحية والأنماط المهمة
- يتعامل مع n-grams (مجموعات الكلمات)
- يحافظ على بناء SQL (حساس للحالة)
- فعال لتصنيف النصوص

**العملية:**
1. نص الاستعلام → تقسيم إلى كلمات
2. استخراج n-grams (1-3 كلمات)
3. حساب درجات TF-IDF
4. إنشاء متجه ميزات ببعد 10,000
5. إدخال إلى نموذج ML
